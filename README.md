# Pronunciation Feedback Practice Planner

A text-only skill that turns an English sentence and feedback you already have into one focused practice loop. It keeps the original sentence intact, chooses a manageable target and leaves a comparison log for your next attempt.

## Use it

Read [SKILL.md](SKILL.md) or load it in an assistant that supports Markdown skills. No account, paid service, API key or network access is needed.

Give the assistant your exact sentence, the feedback you received and the time you have. For example:

> My sentence is “I think these three books are useful.” A previous report flags “three” and “useful”, but I have no numeric score. I have three minutes. Help me plan the next attempt.

The skill returns the evidence it used, one practice target, a timed loop and a blank comparison log. If speaking is impractical, ask for silent preparation and save the spoken attempt for later.

This planner works from supplied text. It does not listen to recordings, score pronunciation, diagnose a condition or certify a language level. Keep personal data out of pasted reports.
